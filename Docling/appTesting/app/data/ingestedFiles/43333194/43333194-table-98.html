AttributeDescription
regexThe regular expression that is used to match against the column or sourceColName's value(s). If replaceWith is absent, each regex is taken as a value and a list of values group is returned.
sourceColNameThe column on which the regex is to be applied. If not present, then the source and target are identical.
splitByUsed to split a string. It returns a list of values. note: this is a regular expression - it may need to be escaped (e.g. via back-slashes)
groupNamesA comma separated list of field column names, used where the regex contains groups and each group is to be saved to a different field. If some groups are not to be named leave a space between commas.

ParameterDescriptionExample
-p Stop Solr running on the given port. If you are running more than one instance, or are running in SolrCloud mode, you either need to specify the ports in separate requests or use the -all option. bin/solr stop -p 8983
-allStop all running Solr instances that have a valid PID.bin/solr

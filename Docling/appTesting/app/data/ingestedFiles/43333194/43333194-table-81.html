Optional ParameterDescription
baseURLSpecifies a new baseURL for pathnames. You can use this to specify host/port changes between Dev/QA/Prod environments. Using this attribute isolates the changes to be made to the solrconfig.xml
connectionTimeoutSpecifies the length of time in milliseconds after which the connection should time out. The default value is 5000ms.
encodingBy default the encoding in the response header is used. You can use this property to override the default encoding.
readTimeoutSpecifies the length of time in milliseconds after which a read operation should time out. The default value is 10000ms.

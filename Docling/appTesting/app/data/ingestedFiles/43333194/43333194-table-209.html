ParameterDescription
maxDocsInteger. Defines the number of documents to queue before pushing them to the index. It works in conjunction with the parameter in that if update_handler_autosoftcommit_max_time either limit is reached, the documents will be pushed to the index.
maxTimeThe number of milliseconds to wait before pushing documents to the index. It works in conjunction with the parameter in that if update_handler_autosoftcommit_max_docs either limit is reached, the documents will be pushed to the index.

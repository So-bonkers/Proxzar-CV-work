UUIDFieldUniversally Unique Identifier (UUID). Pass in a value of "NEW" and Solr will create a new UUID. : configuring a UUIDField instance Note with a default value of "NEW" is not advisable for most users when using SolrCloud (and not possible if the UUID value is configured as the unique key field) since the result will be that each replica of each document will get a unique UUID value. Using UUIDUpdateProcessorFactory to generate UUID values when documents are added is recommended instead.

SettingDescription
exeThe name of the executable to run. It should include the path to the file, relative to Solr home.
dirThe directory to use as the working directory. The default is ".".
waitForces the calling thread to wait until the executable returns a response. The default is . true
argsAny arguments to pass to the program. The default is none.
envAny environment variables to set. The default is none.

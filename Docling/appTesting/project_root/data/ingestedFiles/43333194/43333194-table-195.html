queryFieldTypeSpecifies which fieldType should be used to analyze the incoming text. For example, it may be appropriate to use a fieldType with a LowerCaseFilter.
config-filePath to the file that defines query elevation. This file must exist in /con or . f/ /
If the file exists in the /conf/ directory it will be loaded once at startup. If it exists in the data directory, it will be reloaded for each IndexReader.
forceElevationBy default, this component respects the requested parameter: if the request asks sort to sort by date, it will order the results by date. If (the default), forceElevation=true results will first return the boosted docs, then order by date.

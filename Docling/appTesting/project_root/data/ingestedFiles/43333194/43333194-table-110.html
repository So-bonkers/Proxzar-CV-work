ValueMeaning
explicitThis is the default value. Only parameters included in the actual request, plus the parameter _ (which is a 64-bit numeric timestamp) will be added to the params section of the response header.
allInclude all request parameters that contributed to the query. This will include everything defined in the request handler definition found in as well as parameters included with the solrconfig.xml request, plus the parameter. If a parameter is included in the request handler definition AND the _ request, it will appear multiple times in the response header.
noneEntirely removes the "params" section of the response header. No information about the request parameters will be available in the response.

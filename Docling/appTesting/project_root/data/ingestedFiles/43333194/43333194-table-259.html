NameDescription
locationThe location of the backup snapshot file. If not specified, it looks for backups in Solr's data directory.
nameThe name of the backed up index snapshot to be restored. If the name is not provided it looks for backups with format in the location directory. It picks the latest snapshot. timestamp backup in that case.
repositoryThe name of the repository to be used for the backup. If no repository is specified then the local filesystem repository will be used automatically.

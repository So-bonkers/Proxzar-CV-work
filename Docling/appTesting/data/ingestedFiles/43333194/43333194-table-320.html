TermDefinition
IndexA Lucene index is a directory of files. These files make up the searchable and returnable data of a Solr Core.
DistributionThe copying of an index from the master server to all slaves. The distribution process takes advantage of Lucene's index file structure.
Inserts and DeletesAs inserts and deletes occur in the index, the directory remains unchanged. Documents are always inserted into newly created files. Documents that are deleted are not removed from the files. They are flagged in the file, deletable, and are not removed from the files until the index is optimized.

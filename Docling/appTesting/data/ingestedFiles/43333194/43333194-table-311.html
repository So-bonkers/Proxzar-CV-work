ShortParameter UsageMeaning
-cmd CLI Command to be executed: , , , bootstrap upconfig downconfig linkconfi , , , , , , . g makepath get getfile put putfile list, clear or clusterprop This parameter is mandatory
-z-zkhost ZooKeeper host address. This parameter is for all CLI commands. mandatory

-h-helpDisplay help text.
-n-confname For , : name of the configuration set. upconfig linkconfig, downconfig
-r-runzk Run ZooKeeper internally by passing the Solr run port; only for clusters on one machine.
-s-solrhome For or when using : the solrhome location. bootstrap -runzk mandatory
-name For clusterprop : the mandatory cluster property name.
-val For clusterprop : the cluster property value. If not specified, will be used as null value.

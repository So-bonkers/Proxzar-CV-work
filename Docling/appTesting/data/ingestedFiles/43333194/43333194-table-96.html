AttributeDescription
dateTimeFormatThe format used for parsing this field. This must comply with the syntax of the Java class. SimpleDateFormat
sourceColNameThe column on which the dateFormat is to be applied. If this is absent source and target are same.
localeThe locale to use for date transformations. If not defined, the ROOT locale is used. It must be specified as language-country (BCP 47 language tag). For example, en-US .

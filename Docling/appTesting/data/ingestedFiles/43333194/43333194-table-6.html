ParameterDescriptionExample
-c Name of the collection to run a healthcheck against (required).bin/solr healthcheck -c gettingstarted
-z ZooKeeper connection string, defaults to localhost:9983. If you are running Solr on a port other than 8983, you will have to specify the ZooKeeper connection string. By default, this will be the Solr port + 1000.bin/solr healthcheck -z localhost:2181
